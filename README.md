- **Backend & Cloud**: Node.js, Express.js, MongoDB (Mongoose), Cloudinary Cloud Media API
- **Frontend & 3D**: Streamlit Native UI, React.js, Three.js 3D WebGL Hologram Engine

## 🚀 How to Run Locally

### Option 1: 1-Click Windows Launcher
Double-click:  
`run_streamlit.bat`

### Option 2: Terminal
```bash
streamlit run app.py
```
Open your browser at: **`http://localhost:8501`**

## 🚢 How to Deploy to Streamlit Cloud (1-Click)

1. Create a public repository named `utkarsh-portfolio` on your GitHub account ([https://github.com/new](https://github.com/new)).
2. Push this directory:
   ```bash
   git remote add origin https://github.com/bkutkars-debug/utkarsh-portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Open:  
   👉 **[Deploy to Streamlit Cloud](https://share.streamlit.io/deploy?repository=bkutkars-debug/utkarsh-portfolio&branch=main&mainModule=app.py)**
4. Click **Deploy!** Your app will be live globally for anyone to see with its own URL!
