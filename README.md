## 🛠️ Stack & Capabilities
- **Languages**: Python, C, C++, Java, JavaScript (ES6+), TypeScript
- **Machine Learning & AI**: Scikit-Learn, Backpropagation, Gradient Descent, Multi-Agent Autonomous DAGs (Rakshak AI & Sahayak AI)
- **Data Engineering**: Data Feeding, NumPy Vectorized Math, Pandas DataFrames, Matplotlib Visualizations
- **Backend & Cloud**: Node.js, Express.js, MongoDB (Mongoose), Cloudinary Cloud Media API
- **Frontend & 3D**: React.js, Three.js 3D WebGL Hologram Engine, Modern Glassmorphism, Streamlit Native UI

## 🚀 How to Run Locally

### Option 1: 1-Click Streamlit Launcher
Double-click [`run_streamlit.bat`](run_streamlit.bat) or run:
```bash
streamlit run app.py
```
Open your browser at: **`http://localhost:8501`**

### Option 2: 1-Click Static Web Preview
Double-click `index.html` or open in any web browser.
